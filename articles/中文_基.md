# 基督教世界

基督教世界在各个国家分布的深浅（2014年统计）

基督教世界（英语：Christendom）有多种含义，既可以指全世界的基督徒；也可以指基督徒居多的国家。自从罗马帝国初期基督教自中东沙姆地区传入欧洲与北非之后，基督教始终存在教会分裂现象，形成了以罗马为中心的西方基督教世界、以及以君士坦丁堡为中心的东方基督教世界。在11世纪至13世纪，基督教世界是西方文明的中心。

基督教世界原仅限于欧洲及部分西亚国家，在大航海时代之后，天主教会、新教等西方基督教派系积极开展海外传教活动，加上同时期西方国家的海外殖民行动，使得整个美洲、撒哈拉以南非洲，以及菲律宾、澳大利亚、纽西兰等西太平洋国家，都纳入基督教世界的范围内。

基里尔和美多德（希腊语：Κύριλλος καὶ Μεθόδιος，教会斯拉夫语：Кѷриллъ и Меѳодїи）是东罗马帝国的传教士。他们是两兄弟，在传播基督教正教的同时，同为基里尔字母的发明做出了巨大贡献。他们同时被天主教会和东正教会封为圣人，被称为“圣基里尔和圣美多德”。

## 简介

基里尔在西元826年或827年出生，原名为“康斯坦丁”，基里尔是他在罗马成为修道士时取的圣名。美多德在825年或826年出生，原名为“米哈伊尔”，美多德是他在密细亚的奥林匹斯山成为修道士时取的圣名。他们都出生在萨洛尼卡（位于现在的希腊）。

860年，基里尔和美多德与受东罗马帝国皇帝米海尔三世和君士坦丁堡牧首佛提乌的命令去可萨汗国阻止犹太教的扩张。因为可萨人信奉犹太教可以免除一些政治纠纷，可萨汗国可汗坚定地将犹太教作为国教，所以这次任务失败了。

公元862年，大摩拉维亚的君主罗斯季斯拉夫要求东罗马帝国皇帝米海尔三世和君士坦丁堡牧首弗提乌一世派传教士给斯拉夫人传福音。米海尔三世迅速选择了派基里尔与美多德去，并且说：“你们来自萨洛尼卡，所有的萨洛尼卡人都讲着纯正的斯拉夫语”公元863年，基里尔与美多德对大摩拉维亚和潘诺尼亚的斯拉夫人进行过传教活动。为了向斯拉夫人传教，他们利用希腊字母和一些自创的字母创造了格拉哥里字母。格拉哥里字母是第一种用来记录古教会斯拉夫语的字母。随后他们将圣经翻译成古教会斯拉夫语，并在摩拉维亚推广了它。

在867年，教皇尼古拉一世邀请基里尔与美多德去罗马，869年2月14日，基里尔在罗马去世。870年，美多德返回摩拉维亚并在885年4月6日在那里去世。

两兄弟后来都被东正教会授予“斯拉夫人的传教士”的头衔。1880年，天主教教皇利奥十三世在天主教将他们的庆日加到天主教的礼仪历中。1980年，天主教教宗若望·保禄二世宣布他们与诺尔恰的圣本笃同为欧洲的主保圣人。

### 圣基里尔和圣美多德日

信奉东正教的国家一般将儒略历5月11日（公历5月24日）定为“圣基里尔和圣美多德日”，而信奉天主教的国家一般将7月5日定为“圣基里尔和圣美多德日”。

现在，“圣基里尔和圣美多德日” 作为公共节日在下列国家庆祝：

- 在保加利亚人们在5月24日纪念基里尔与美多德，节日的正式名称为“保加利亚教育、文化、和斯拉夫文学日”（保加利亚语：Ден на българската просвета и култура и на славянската писменост），一个用来纪念保加利亚文化、文学、与基里尔字母的节日。它被人们称为“字母、文化和教育节”（保加利亚语：Ден на азбуката, културата и просвещението）。基里尔与美多德被看成是保加利亚国家图书馆的保护人。保加利亚国家图书馆前面就有他们的纪念馆。

- 在马其顿，人们在5月24日纪念基里尔与美多德，节日的名称为“圣基里尔和圣美多德日”（马其顿语：Св. Кирил и Методиј, Ден на словенските просветители）。

- 在捷克，7月5日是“圣基里尔和圣美多德日”（捷克语：Den slovanských věrozvěstů Cyrila a Metoděje）。

- 在俄罗斯，5月24日是“斯拉夫文学与文化节”（俄语：День славянской письменности и культуры），庆祝斯拉夫文学、文化与字母。

- 在斯洛伐克，7月5日是“圣基里尔和圣美多德日”（斯洛伐克语：Sviatok svätého Cyrila a Metoda）。

## 沿革

862年，留里克创立诺夫哥罗德公国，是为罗斯诸国的开始。882年，第二代诺夫哥罗德大公奥列格夺得基辅，创立基辅罗斯。基辅罗斯创立早期，汇聚周边族群，统一了区域内罗斯人的管治秩序。伊戈尔继位后，创立留里克王朝，开启首个罗斯王朝。基辅罗斯在这段时间屡次出兵劫掠拜占庭帝国、保加利亚第一帝国、可萨汗国等周边领土。

智者雅罗斯拉夫死后，长子、次子、四子分别争位，基辅罗斯小分裂，最终由四子弗谢沃洛德再度统一，是为弗谢沃洛德一世。弗谢沃洛德之子红太阳莫诺马赫打败南俄草原的波洛韦茨人，消除了突厥人对基辅罗斯的威胁。红太阳莫诺马赫死后，基辅罗斯大分裂，他的长孙伊贾斯拉夫二世·姆斯季斯拉维奇曾统一大部分基辅罗斯，但被七叔尤里·多尔戈鲁基所败，基辅罗斯再度陷入无主状态。1169年，尤里·多尔戈鲁基长子安德烈·博戈柳布斯基联合十六个大公国的军队攻陷基辅，迁移共主中心至弗拉基米尔，再度名义上统一基辅罗斯的秩序，但一年后再次陷入分离状态。安德烈·博戈柳布斯基死后，除了其弟大窝弗谢沃洛德能暂时稳定局势外，基辅罗斯长时间陷于诸国争权。后在长子西征中，基辅罗斯被拔都为首的蒙古侵略军瓦解，进一步分离正统宗主继承权威。

# 基督教神学史

基督教会的神学史（History of Christian theology）是基督教教义的历史，被三位一体论者视为基督教神学的核心，是教会不断探索圣经资料的结果，在辩论和论文中反复讨论，最终以某种方式在公元 325 年的第一次尼西亚公会议上形成。他们相信这与圣经见证一致，并在后来的会议和著作中得到进一步完善。

神学是有关「神」的「学」问。 神学是教会的工具，然而神学不是代表教会的，它不像教义是教会官方的规条，神学仅是供个人的研究与探讨；但是它却不能肆无忌惮，无的放矢，因为神学是要为教会所用的。

# 基奥贾战争

基奥贾战争(或翻译为吉奥佳战役，义大利语：Guerra di Chioggia)为威尼斯共和国与热那亚共和国在1378年至1381年所发生的战争，由威尼斯获得了最后的胜利。另外，此次战争可视为威热战争的一部分，为第四次（依算法不同或为第三次）威热战争。

## 背景

威尼斯与热那亚两个海权强国从中世纪就借由与君士坦丁堡的贸易来发展，因此也为了贸易在东地中海发生过数次冲突。在1350-1355年的第三次威热战争中，热那亚一度被威尼斯重创，因此接受统治米兰的维斯孔蒂家族的金援，成为米兰的从属国。虽然热那亚很快就还清了债务，并摆脱米兰的控制。但仍未从公元1348年那场造成热那亚40000人死亡的黑死病中完全复苏。同时，威尼斯虽然在财务上也逐渐从战争的损失中恢复，但却面临了北方匈牙利的威胁，被迫放弃了许多土地。也因为领土的扩张而与帕多瓦产生冲突。

## 联盟

热那亚的盟友主要包含了匈牙利及帕多瓦。匈牙利的国王拉约什一世从威尼斯手中征服了达尔马提亚，并在公元1379年时从陆路给予威尼斯北方直接的威胁。而帕多瓦则是在卡卡雷西家族的领导下切断了威尼斯与西方的联系。此外，阿奎莱亚和奥地利公爵利奥波德三世也是站在热那亚这边。

# 基辅罗斯–拜占庭条约 (911年)

罗斯-拜占庭条约（公元911年）是拜占庭帝国与基辅罗斯间缔结的一份文件，属于907年条约的跟进一步协定，相对更全面和详尽地达成了协议内容。这份文件被认为是古罗斯法律最早的书面起源。

被编入编年史内的条约文本，在内容和措辞上与拜占庭后面与意大利商业共和国达成的贸易协定有许多相似点。文件是双语书写，由拜占庭皇帝利奥六世亲笔签署。文本还包括各方曾在活动中的发言。在当时欧洲，如其兼具复杂而古老的条约，据所知并未有于其他社区里出现过。

条约开篇详列出罗斯使者名字（括注是验证过或重制的古挪威语形式）：Farlof ( Farulfr )、Ver/lemud ( Vermu(n)dr )、Rulav ( Rollabʀ )、Fost (* Fastuʀ )、 Frelavc ( Frilleifr ), Ingeld ( Ingjaldr ), Karly ( Karli ), Karn ( Karna, 于瑞典符文型铭文铭文可验证), Lidul(f) ( Lidulif < Leiðulfr, 但litulf由符文型铭文铭文可验证), Ruald ( Hróaldr ), Rjuar ( Hróarr ), Truan ( Þróndr或Þrandr )。 

后面第3至7条是规约了在君士坦丁堡，他们的殖民地上的刑法和生活（守则）。里面也还有个关于在帝都身故商人（身后）继承权利的附加生效条款。第8条专门谈及到海事法。再后条文就详细约定了俘虏的赎金、罪犯的交接以及在拜占庭服役的瓦良格雇佣兵的法定地位。

# 基里巴斯历史

至少在700年前，今基里巴斯共和国岛上就有人类居住。最早的基里巴斯岛上为密克罗尼西亚人，他们至今仍占大多数人口。

## 史前

至少在2000年前，密克罗尼西亚人已经开始在基里巴斯岛上居住。在大约前3000年至1300年，吉尔伯特人在吉尔伯特岛上居住。之后，有着波利尼西亚元素的萨摩亚人，汤加人以及美拉尼西亚元素的斐济人进入此地。但是不同种族之间的大量通婚使得基里巴斯文化显得不太差异。

## 早期接触

1606年，佩德罗·费尔南德斯远望了基里巴斯岛。1764年，约翰·拜伦在他的环球航行中路过基里巴斯岛。1788年，船长托马斯·吉尔伯特和另一个船长约翰·马绍尔路过此地，他们并没有尝试登岸。

## 进一步探索

1820年，此岛被命名为吉尔伯特岛。1828年和1838年，美国的休斯敦船长访问了基里巴斯岛。

## 殖民时期

19世纪，捕鲸船、奴隶贸易和商业活动在基里巴斯大量出现。这个导致了与当地部族的冲突和欧洲疾病的引入。1892年，吉尔伯特岛与邻近的埃利斯群岛（今图瓦卢）成为英国的保护地。1916年，此地与范宁岛、华盛顿岛整合成为英属吉尔伯特和埃利斯群岛。这个是为英属西太平洋领土一部分。

## 第二次世界大战

在第二次世界大战中，日本帝国占领了一部分岛屿，形成了岛屿链防御。1943年11月20日，盟军在吉尔伯特岛与日军进行血腥的太平洋战役。

## 前途自决

20世纪60年代，英国让岛上的自治政府扩大权力。1975年，埃利斯群岛分离形成独立国家图瓦卢。1977年，吉尔伯特岛获得内部自治。

## 独立

1979年7月12日，最终以基里巴斯的国名获得独立。

# 基辅罗斯–拜占庭条约 (945年)

944年或945年所缔结的罗斯–拜占庭条约，是作为940年代初期基辅罗斯对君士坦丁堡所进行的一次海上远征而致的结果，其由拜占庭皇帝君士坦丁七世和基辅的伊戈尔一世所签订。该文件的条文，与伊戈尔前任奥列格所关联的先前协定条文相比起来，是对基辅罗斯较为不利的。该文件也是古罗斯法里最早的书面信源之一。

于往年纪事中存续的条约文本，包含了当时罗斯全权代表的名录（不少于五十名）。绝大多人都有诺斯人的名字。 记述当时宣誓时，有一部分罗斯的使者是援引他们的异教神之名发誓，而另一部分人则是援引基督教神之名，如此是表明了这时候有一部分罗斯菁英是已接受基督教化。

署名总人数为76名，其中有属于统治家族的12人，使者有11人，其他类别的代理人有27人，商人有26人。在这些留名的王公成员里，有三个斯拉夫名字Svjatoslav ，王公伊戈尔· (Ingvar) 和Volodislav和Predslava （关系不明）的儿子。王家的其他成员则留下有诺斯人，即Olga ( Helga)、Akun (Hákon)、Sfanda ( Svanhildr )、Uleb (Óleifr )、Turd ( Þórðr )、Arfast ( Arnfastr ) 和 Sfir'ka (Sverkir )。使者方面除三人有芬兰名字，他们都也有古挪威人的名字。 Olga的代表是芬兰人名的Iskusevi ，而 Volodislav 的代表是诺斯人 Uleb ( Óleifr )。 27名代理人之中，有人拥有芬兰人的名号，但没有斯拉夫人的；26名商人之中，有芬兰人名3个，斯拉夫人名两个。 

944/945年的条约，是重申了先前定居点协定的一些条款。在该次协议里，基辅罗斯一方许诺不会再袭击拜占庭在克里米亚的飞地克森尼索 （第8 条）。另外第聂伯河（ 别列赞岛 ）按约定会接受联合管治，尽管罗斯人同时被禁止在那里过冬或欺压来自克森尼索的渔民（第12条）。

条约内的第2条，增加了关于海商法的新约定：其为区分一般商人和掠夺者而列明，要求来自罗斯的每艘船都要携带有一份基辅王公的特许状，以说明有多少人和多少艘船将驶往君士坦丁堡。否则，罗斯船只就可能会被帝国当局拘押。

基比拉奥特军区，更应该说是基比拉奥特人的军区（希腊语：θέμα Κιβυρραιωτῶν，罗马化：thema Kibyrrhaiōtōn）, 在8到12世纪晚期覆盖了整个安纳托利亚的西南海岸。也是帝国第一个也是最重要的海军军区（古希腊语：θέμα ναυτικόν，罗马化：thema nautikon），为帝国提供了船舰和大量的水兵。

## 历史

基比拉奥特军区在拜占庭帝国的位置

基比拉奥特（希腊语：Κιβυρραιῶται，罗马化：Kibyrrhaiōtai，意为"基比拉人"）发源于基比拉城（但还不确定是卡里亚的大基比拉城还是潘菲利亚的小基比拉城）。军区在698年为了支援倭马亚远征迦太基而成立的，最早被证实的军区指挥官是阿普西玛，是在科利科斯指挥军队的“基比拉奥特海军提督”，再之后他推翻利昂提奥斯成为提比略三世。在当时基比拉奥特是东罗马海军的下属单位。

在东罗马海军解散之后（有一说是719/720年，另一说是727年），基比拉奥特便作为常设军区存在，在731/732年中央政府便开始在此处任命掌管该军区的将军，直到9世纪为止，在萨摩斯和爱琴群岛被设立海军军区并指派提督之前，基比拉奥特是帝国唯一的海军军区。

军区的下辖领土从米利都（色雷斯西亚军区的下辖地区）南部一直延伸到奇里乞亚（当时阿拉伯的边区），囊括了罗马故地的卡里亚，吕基亚，潘菲利亚和部分的伊苏里亚（今十二群岛）行省，作为前线直面着来自于黎凡特和埃及的穆斯林军队，并且在拜占庭-阿拉伯战争中的海上战争起到至关重要的作用。虽然土地一直以肥沃著称，但长久来自于阿拉伯人的劫掠使得当地乡下人口稀少，人口大多在有城防的城市以及海军基地之中。

军区的首府自然而然便设在了阿塔勒亚，即现在土耳其的安塔利亚，他领有10磅黄金的年俸，即使在帝国的位阶并非高位，但在其他海军军区里仍属头筹。

与别处军区不同的是，基比拉奥特军区被分为海军提督区和副军区，但各自都有完整的军区级的编制。在将军的诸多手下之中最受倚重的便是驻在希利永的帝国督军，阿塔勒亚和科斯的海军提督和指挥马代特人的将领，马代特人为查士丁尼二世在7世纪80年代安置在此地的数千黎巴嫩难民的后裔，为东罗马的海军提供船员和水兵。在9世纪早期，基比拉奥特的海军舰队共有70艘船只，而在911年的克里特远征时期，基比拉奥特派遣了31战船（15艘大型的快速战舰和16艘重型帆船），上面载着6000名划桨手和760名海军士兵。

随着11世纪中期穆斯林诸国的海上威胁逐渐衰退，拜占庭帝国的舰队便迅速被打入冷宫，基比拉奥特的舰队最后一次有记录的出征是在1043年去黑海对抗北方的基辅罗斯。在此之后军区逐渐退化成为一般省份，当地的首长从军区将军变成了仲裁官，在之后则成了驻防长官。1071年之后大多数的土地沦陷于塞尔柱帝国之手，但是在阿莱克修斯一世时期收复了一部分，这个残存的军区最终被曼努埃尔一世废除，而在卡里亚地区的原军区领土被并入米拉萨和梅兰努迪翁军区。

# 基辅的狄奥格诺斯图斯

基辅的狄奥格诺斯图斯

基辅的狄奥格诺斯图斯（英文: Theognostus of Kiev, 俄文：Феогност，1353 年3月11日去世 ）出生于君士坦丁堡，在君士坦丁堡大牧首以赛亚 (Patriarch Isaiah of Constantinople 1323-1334 ) 的祝福下，他接替圣彼得成为基辅和全俄罗斯都主教，并于 1327 年至 1353 年担任这一职务。

## 生平

彼得都主教去世后（1327 年），狄奥格诺斯图斯被任命为基辅和全俄罗斯都主教。

在诺夫哥罗德与莫斯科亲王互有敌意的时候，狄奥格诺斯图斯协助调解了诺夫哥罗德与莫斯科王子的关系。在拒绝从教堂收取贡品给蒙古人后，狄奥格诺斯图斯设法保存了教堂的所有贵重物品，并放弃了他的所有个人财产。他因胆大妄为而受到鞑靼人的严刑拷打，但他从未屈服。

一场大火席卷莫斯科后，狄奥格诺斯图斯尽管已经一无所有，但仍开始修复教堂。正是透过他的影响，西蒙大公向罗马皇帝约翰·坎塔库津（John Cantacuzene）捐款，以修复君士坦丁堡的圣索菲亚大教堂。

在他生命的尽头，当需要指定继任者时，都主教狄奥格诺斯图斯坚持认为这一职位只能由长期担任修道院的人担任。 1353年，狄奥格诺斯图斯因遭受瘟疫而感到自己时日无多，于是任命弗拉基米尔主教亚历克西斯为他的继任者。他于3月11日安息。

狄奥格诺斯图斯被安葬于莫斯科的圣母安息大教堂。1471年，他的遗物被发现完好无损。 19世纪，他被俄罗斯东正教封为圣人。

# 基辅罗斯的基督教化

克劳迪乌斯·列别杰夫所作《罗斯受洗》

基辅罗斯的基督教化分几个阶段进行。867年初，君士坦丁堡普世牧首佛提乌向其他基督教宗主教宣布，在他的主教的洗礼下，罗斯人特别热情地接受了基督教。佛提乌试图将这个国家基督教化似乎并没有带来持久的后果，因为《往年纪事》和其他斯拉夫语资料将十世纪的罗斯描述为在异教中根深蒂固。在《往年纪事》之外，基辅罗斯的最终基督教化可以追溯到988年，当时弗拉基米尔大帝在克森尼索受洗，并随后在基辅为他的家人和人民施洗。后者在乌克兰和俄罗斯文学中传统上被称为罗斯受洗（俄语：Крещение Руси, 乌克兰语：Хрещення Русі）。

# 基督普世君王圣像

基督普世君王圣像

基督普世君王圣像位于圣凯瑟琳修道院内，是东罗马帝国的宗教圣像画，它的历史可追溯至公元6世纪。 它也是现存最早的耶稣的画像。 

当时圣凯瑟琳修道院的建造得到了查士丁尼及东罗马帝国朝廷的赞助，基督普世君王圣像可能是就是东罗马帝国朝廷赐予的。 因此人们普遍认为这幅圣像制作于拜占庭首都君士坦丁堡。

基菲里清真寺（土耳其语：Kefeli Câmîi，意为“卡法人清真寺”，得名于克里米亚的卡法城）是土耳其伊斯坦布尔一座原基督教教堂改建的清真寺。在历史上它曾属于东正教、罗马天主教和亚美尼亚使徒教会，最后被奥斯曼帝国改为清真寺。

该建筑位于土耳其伊斯坦布尔法蒂赫区Salmatomruk社区，科拉教堂和征服者清真寺（Fethiye）的中间。

## 历史

在君士坦丁堡的历史上，此处曾是一个颇为重要的修道院，坐落在君士坦丁堡第六山的山坡上。皇帝狄奥斐卢斯在位期间（829–842年)，抵御阿拉伯人的将军亚美尼亚的Manuel将住宅改为修道院，靠近阿斯帕蓄水池。Manuel是皇后狄奥多拉的叔叔，皇帝去世后，他协助太后辅佐年仅两岁的幼主米海尔三世，退隐后进入修道院隐修。后来牧首佛提乌和罗曼努斯一世（920–944年在位）都曾重修修道院。皇帝米海尔七世（1071–1078在位）被废黜后也在此隐修。后来，这里曾是供奉圣尼各老的天主教堂。

# 基辅的伊西多尔

基辅的伊西多尔

基辅的伊西多尔（1385年－1463年4月27日）是一位具有拜占庭罗马人血统的教长。1437年至1441年期间，他是莫斯科及全罗斯牧首。他支持莫斯科大公国与东罗马帝国结盟。

他曾参加佛罗伦斯大公会议，但在1441年回到莫斯科大公国后被囚禁，莫斯科大公国方面表示他回到莫斯科大公国后只知道尊重教皇却不尊重东正教。不久后基辅的伊西多尔释放。但莫斯科大公国已经不承认他是莫斯科及全罗斯牧首 。1448年，俄罗斯正教会选出了自己的都主教。 然而君士坦丁堡牧首一直承认基辅的伊西多尔才是莫斯科及全罗斯牧首，而且任期至1458年。 

伊西多尔后来来到君士坦丁堡，并于1452年12月12日在圣索菲亚大教堂宣布希腊教会和拉丁教会联合。君士坦丁堡陷落后，他返回罗马。基辅的伊西多尔还曾担任天主教萨比娜-波焦米尔泰托罗马城郊教区的枢机 以及君士坦丁堡拉丁宗主教。

基辅的奥莉加（教会斯拉夫语：Ольга；古诺斯语：Helga；890年至925年间—969年7月11日）是基辅罗斯第一位女大公和基辅大公伊戈尔的妻子，于945年—957年在位。她也是斯维亚托斯拉夫·伊戈列维奇大公的母亲和摄政。

## 事迹

一般认为奥莉加具有瓦良格（即维京人）血统，而奥莉加其名于瓦良格人通用的古诺斯语之形式，大概就是“Helga”。据信她出生于普斯科夫，并约在903年，嫁给了未来的大公、留里克之子伊戈尔。古史书《往年纪事》记载奥莉加的出生日期为879年；然而对照其子斯维亚托斯拉夫·伊戈列维奇的相关资料，则这是相当不可能的。因为那样的话，斯维亚托斯拉夫·伊戈列维奇出生时她已经有65岁了。

910年代左右，奥莉加的丈夫伊戈尔经过长年征战，统辖众部落与大片领土，建立起古罗斯国家的雏形。945年，伊戈尔外出索贡巡行时，因企图征取双倍的贡赋，于伊斯科罗斯坚一地为德列夫利安人所杀。德列夫利安人为避免遭罗斯国报复，向奥莉加派来两名使者，建议她嫁给他们的首领马尔公爵。奥莉加下令处死了这两个使者，随后对德列夫利安人进行了残酷的报复。她下令屠杀近5000名德列夫利安人，摧毁他们的聚居地，据说她甚至把俘虏烫死。946年奥莉加烧毁了德列夫利安人的城市伊斯科罗斯坚，因为伊戈尔死于该城附近。根据一个真实性不能确定的故事，奥莉加要求每个德列夫利安人家庭上缴一只鸽子，然后下令将燃烧物绑在鸽子的腿上，再将它们放飞回去。结果每个德列夫利安人的房子都被这些“燃烧弹”焚毁了。

奥莉加是其子斯维亚托斯拉夫·伊戈列维奇大公年幼时的摄政。在斯维亚托斯拉夫成年后，奥莉加仍然是基辅罗斯的实际统治者，因为斯维亚托斯拉夫几乎一生都率领亲兵在外远征。为避免因任意索取贡赋激化与人民的矛盾，奥莉加制定了古代罗斯最早的征收贡赋的标准，并且建立了固定的税区。

奥莉加是第一个皈依基督教的罗斯统治者。为加强与拜占庭帝国的联系（罗斯与拜占庭的关系始于911年奥列格对拜占庭的远征），奥莉加于955年（此为俄国编年史所载日期；拜占庭方面的文献则记载为957年）前往帝都君士坦丁堡。她在那里受洗成为一名基督教徒，并得到一个基督教名字叶莲娜（Елена，源自于当时拜占庭帝国皇后海伦娜·拉卡平娜的名字）。这次来访在拜占庭皇帝君士坦丁七世的著作《De Ceremoniis》中有详细记载。但她在回国后，并没有兑现向拜占庭提供军事援助的承诺。根据不确定的记载，奥莉加也曾与神圣罗马帝国皇帝奥托一世也建立过联系。

968年，奥莉加与她的三个孙子（亚罗波尔克·斯维亚托斯拉维奇，奥列格·斯维亚托斯拉维奇和弗拉基米尔·斯维亚托斯拉维奇）一起被突厥游牧部落佩切涅格人围困在基辅（佩切涅格人受到拜占庭政府的唆使），后来其子斯维亚托斯拉夫从保加利亚带兵返回才得以解围。

奥莉加在罗斯传播了基督教信仰。虽然她没能使自己的儿子斯维亚托斯拉夫皈依基督教（但她说服斯维亚托斯拉夫不在她死后为她举行异教的入葬仪式），其孙弗拉基米尔在罗斯实行彻底基督教化（即罗斯受洗）的政策却极有可能受到了她的影响。奥莉加为俄罗斯正教会最早追认的圣人之一，而今日俄罗斯滨海边疆区的奥莉加区及其首府奥莉加亦以之为名。

# 基辅罗斯–拜占庭条约 (907年)

首个罗斯–拜占庭条约， 依据往年纪事，是于907年由奥列格对君士坦丁堡作出突袭所引致缔结的（参见罗斯-拜占庭战争（907） ）。学者们普遍认为，该文件属于911年罗斯与拜占庭条约的初步文件。

保存在编年史中的条约文本，开篇有列出基辅罗斯一方当时的签署代表名录。在这15个签名之中，有两个可能是芬兰人的名字，而其余人的就明显属古诺尔斯语的名字 （括注内为可证的古诺尔斯语写法）：Karly ( Karli )、Ingeld ( Ingjaldr )、Farlof ( Farulfr )、Ver /lemud ( Vermu(n)dr ), Rulav ( Rollabʀ ), Stemid/Stemir ( Steinviðr ), Karn ( Karn ), Frelav ( Friðláfr ), Ruar ( Hróarr ), Truan ( Þrándr ), Gudy ( Góði ), Ruald ( Hróaldr ) 和福斯特 ( Fastr )。 

最受瞩目的是，该条约列明了在君士坦丁堡内瓦良格商人殖民地的法定地位。文本证明他们曾在圣妈妈区（Saint Mamas）定居。依据约定，瓦良格人是要通过特定门岗进入君士坦丁堡，且不能携带武器并由皇家卫队陪同，每次出入都不能过五十人。他们抵达后必须接受当地皇家部门的登记，以换取半年时间内可获得食物和月度给养品。

依据记述，条约收尾的（宣誓）部分里，拜占庭人一方是亲吻十字架（为誓），而瓦良格人一方则举起他们的手臂，援引编年史记述的霹隆和韦莱斯之名为誓。

基利杰阿尔斯兰二世（土耳其语：II. Kılıç Arslan；波斯语：قلج ارسلان دوم，他的名字解作「剑狮」）在1156年登基为塞尔柱王朝鲁姆苏丹国的苏丹，直至1192年时逝世。

## 统治

依据历史学者吕贝克的阿诺德所撰写的文献纪录，1172年，公爵狮子亨利在前往耶路撒冷朝圣的旅途中与基利杰阿尔斯兰二世相遇，两人于塔尔苏斯附近碰面，会面中苏丹拥抱并亲吻了亨利，并提及他们为血脉相连的远房兄弟，当亨利就此事细问，基利杰阿尔斯兰告诉他：「一位日耳曼的女贵族嫁给了罗斯的君主，他们的孙女来到这片土地，我正是她的后裔。」基利杰阿尔斯兰话中所提到的那位王公应为斯维亚托斯拉夫二世·雅罗斯拉维奇，他所迎娶的第二任妻子施塔德的奥达为狮子亨利的远亲。

当拜占庭皇帝曼努埃尔一世于1159年与努尔丁谈判完毕从叙利亚返国途中，途经鲁姆苏丹国首都以哥念（今日土耳其的科尼亚）时被基利杰阿尔斯兰袭击。1161年，在曼努埃尔的甥侄约翰·康铎斯特法诺斯率军击败基利杰阿尔斯兰后，基利杰阿尔斯兰亲身前往君士坦丁堡归顺。1173年，正与拜占庭人处于和平状态的基利杰阿尔斯兰和努尔丁结盟，两人携手对抗摩苏尔的统治者。

尽管鲁姆苏丹国与拜占庭帝国皆广设防御工事并积极组建军队，以准备应对新一轮战争的到来，不过两国的和睦关系仍延续至1175年，直到基利杰阿尔斯兰拒绝将他新征服达尼什曼德王朝所得来的土地转交给曼努埃尔，导致曼努埃尔决定派兵出击塞尔柱人，纵使基利杰阿尔斯兰仍尝试透过和谈来解决双方的纠纷，但曼努埃尔依旧于1176年发兵入侵鲁姆苏丹国，兵锋直指以哥念，幸运的是基利杰阿尔斯兰在密列奥塞法隆战役击败曼努埃尔的大军，迫使皇帝接受谈判并签下一纸维系两国脆弱和平的条约。

1179年，著名的香槟伯爵亨利一世在结束耶路撒冷的朝圣之旅循陆路返程途中，被基利杰阿尔斯兰擒获并遭到扣押。直至拜占庭皇帝曼努埃尔帮忙支付赎金后亨利才被释放，但他在获释不久后去世。

当曼努埃尔一世于1180年病逝后，拜占庭帝国政局陷入严重的动荡，基利杰阿尔斯兰则趁著这个机会，顺势巩固鲁姆苏丹国在南安那托利亚大部分的疆域，并于同年派出他的维齐尔伊赫蒂亚尔丁与努尔丁的继承者萨拉丁结盟。在1182年，基利杰阿尔斯兰攻克拜占庭人掌控的城市屈塔希亚。1185年，他与登上拜占庭皇位的伊萨克二世讲和停止战争，翌年他将实权下放给他的九名儿子，但他们旋即为了争夺权力爆发激烈的冲突。虽然基利杰阿尔斯兰已与萨拉丁缔结为盟友，但他仍未能阻止第三次十字军东征进攻的步伐。

12世纪后期，基利杰阿尔斯兰下令于首都以哥念修筑塞尔柱式的建筑阿拉丁清真寺 。

在宣布凯霍斯鲁一世为他的王位继承人后，基利杰阿尔斯兰于1192年去世。他死后凯霍斯鲁一世继位，但基利杰阿尔斯兰其余的儿子们仍为争夺鲁姆苏丹国各地领土的控制权而相互交战。
