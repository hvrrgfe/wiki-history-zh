# 强迫皈依

强迫皈依是指有人在外界的胁迫下皈依其他宗教或改成无宗教信仰。 被迫皈依其他宗教或被迫改成非宗教信仰的人可能会继续依然坚持自己的信仰，不过他会装作自己已经改信其他宗教。

# 强盗骑士

强盗骑士（英语:robber baron或robber knight，德语:Raubritter）是中世纪欧洲一些从事盗匪活动的骑士。

他们战时是雇佣兵，平日则以强取过高额路费作生计，也以决斗制度为名抢夺对方财产作战利品。

这些人在14世纪时因神圣罗马帝国皇帝取缔而消失。

# 强者罗贝尔

强者罗贝尔（法语：Robert le Fort；820年—866年7月2日），罗贝尔王朝的始创人。罗贝尔原先是东法兰克出自埃斯拜伯爵家族，父亲是沃姆斯及莱茵高伯爵沃姆斯的罗贝尔三世。父亲于834年逝世后，罗贝尔继承爵位，被称为“沃姆斯的罗贝尔四世”。

当日耳曼人路易统治东法兰克王国时，罗贝尔家族举家投奔西法兰克王国的开国君主秃头查理，852年，罗贝尔受封马尔穆捷的俗家修道院长，再于853年受封曼恩公爵，统治曼恩、安茹、图赖讷等地，成为以勒芒地区为中心的公国、相当于墨洛温王朝时代的纽斯特里亚，罗贝尔逐渐取代当地的贵族，成为当地对抗维京人及布列塔尼人侵略的守护者。

858年，罗贝尔加入了反对国王秃头查理的叛乱。在布列塔尼人的领袖布列塔尼的所罗门及纽斯特里亚的法兰克人贵族参与下，并邀请东法兰克王国国王日耳曼人路易入侵西法兰克王国以接受他们的贡品。这场叛乱是由于秃头查理和布列塔尼国王埃里斯波之间的婚姻联盟而引起的，秃头查理的长子口吃者路易于856年迎娶埃里斯波的女儿，并建立纽斯特里亚王国以作封邑，此举大大削弱罗贝尔及布列塔尼的所罗门的权力，秃头查理给了罗贝尔勃艮第的欧坦及讷韦尔以作补偿；而在856年，罗贝尔在日耳曼人路易的入侵下保卫欧坦。 但是随著埃里斯波于857年11月被暗杀后，罗贝尔和布列塔尼的所罗门起来反叛秃头查理。

865年打败入侵塞纳河流域的诺曼人，866年国王将治理纽斯特里亚（今天法国中部）的全权交给他，成为纽斯特里亚国王。866年7月2日死于与诺曼人的战斗中（Brissarthe之战）。

罗贝尔为厄德一世和罗贝尔一世两位西法兰克国王之父，也是法国历史上的卡佩王朝创建者雨果·卡佩的曾祖父。其中罗贝尔是他的遗腹子。
