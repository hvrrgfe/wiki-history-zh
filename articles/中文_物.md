# 物部尾舆

| 
 | 日语写法
 | 日语原文 | 物部 尾舆
 | 假名 | もののべ の おこし
 | 平文式罗马字 | Mononobe no okoshi

物部尾舆（生卒年不详）是日本6世纪中叶的一位物部氏豪族。他在安闲天皇、钦明天皇两朝担任大连一职。其父为物部荒山。有一子物部守屋。

531年（安闲天皇元年），庐城部枳莒喻的女儿偷走了物部尾舆的首饰，献给了皇后春日山田皇女，被发觉。尾舆对此事件十分恐惧，将配下的部民献给了皇后。钦明天皇继位后再次担任大连之职。539年（钦明天皇元年），大伴金村将任那四郡割让给了百济，物部尾舆非难他，迫使金村从政界引退。552年（钦明天皇十三年），百济圣明王将佛像、佛经等送给日本朝廷（佛教公传）。物部尾舆与中臣镰子一起主张废除佛教（废佛派），与崇佛派的苏我稻目对立。
