# 盖罗

14世纪对盖罗的描绘

盖罗一世（德语：Gero I，约900年－965年5月20日），有时被称为盖罗大帝（拉丁语：magnus），是一位德意志人贵族，他统治着最初以梅瑟堡为中心的边疆区，该边疆区位于现在的德国萨克森-安哈尔特州南部，他将其扩展到以他命名的广阔领土：盖罗边疆区。在10世纪中叶，他是撒克森人的领袖。他大大推动了德国人东向殖民运动的进展。

# 盖佐二世

描绘在匈牙利编年史中的盖佐二世

盖佐二世（匈牙利语：II. Géza；克罗埃西亚语：Gejza II；斯洛伐克语：Gejza II；1130年—1162年5月31日），阿尔帕德王朝匈牙利及克罗地亚国王（1141年—1162年在位）。贝拉二世与其妻子塞尔维亚公主伊洛娜所生的长子，拉斯洛二世及伊什特万四世的兄长。

## 早年

1129年，当伊什特万二世知道其堂弟贝拉二世并未死去时，他很高兴并接他回国，赐托尔瑙为他的封地，并为他娶了塞尔维亚公主伊洛娜为妻。1130年，盖佐二世出生。1131年春天，伊什特万二世逝世，他的指定继承人扫罗亦于同年早前逝世。王位由贝拉二世继承。数月后，伊洛娜带了盖佐二世及其弟拉斯洛在阿拉德举行了集会，在此她下令屠杀了68位因他们的意见而弄盲贝拉二世的大臣。

## 统治期间

1141年，父亲贝拉二世逝世时，盖佐二世仍是孩童，只得11岁，由他的母亲伊洛娜及他的舅父别劳许摄政。直至1146年，盖佐二世才亲政。盖佐二世是匈牙利历史上最有权力的君主之一，他多次成功介入邻国的内政。

1145年，卡尔曼与第二任妻子基辅的埃乌费米亚所生的私生子（匈牙利国民不承认他的地位，基辅的埃乌费米亚是因通奸而被逐出匈牙利）鲍里斯投靠神圣罗马皇帝康拉德三世，因为波希米亚公爵弗拉迪斯拉夫二世的推介下，皇帝准许他率领巴伐利亚和奥地利雇佣兵军队攻入匈牙利，并取下普莱斯堡。王家卫队迅速围住普莱斯堡，并以补偿诱使雇佣兵军队不抵抗下投降。匈牙利人怨恨神圣罗马皇帝国一手速成鲍里斯的入侵，决定攻打神圣罗马皇帝国。在16岁的盖佐二世及其舅父的带领下，匈牙利军队于同年的9月11日在菲莎战役中打败了由奥地利藩侯亨利二世率领的帝国军队。

1146年，盖佐二世与基辅大公伊贾斯拉夫二世·姆斯季斯拉维奇的姊姊基辅的欧芙洛绪涅结婚。与神圣罗马帝国的关系因鲍里斯趁皇帝康拉德三世发动十字军东征，要求率军经过匈牙利至圣地，令双方关系仍然紧张。当十字军行经匈牙利时，因为盖佐二世懂得用金钱派给各德意志诸侯，所以他们并没有攻击匈牙利。据匈牙利编年史记载，虽然国王已经下令如鲍里斯途经匈牙利，便重金活捉他，但是鲍里斯仍在法国国王路易七世的保护下经过匈牙利，最后鲍里斯在拜占庭帝国定居。

1140年代未，因西西里入侵拜占庭帝国，拜占庭帝国科穆宁王朝的皇帝曼努埃尔一世与西西里国王鲁杰罗二世对立。曼努埃尔一世拉拢神圣罗马皇帝康拉德三世结盟，而盖佐二世就与鲁杰罗二世结盟对抗。

1148年春天，盖佐二世增援其妻舅伊贾斯拉夫二世·姆斯季斯拉维奇以对抗切尔尼戈夫公爵弗拉基米尔·达维多维奇的对战。1149年8月，伊贾斯拉夫·姆斯季斯拉维奇至少有两次被苏兹达尔王公尤里·多尔戈鲁基赶出基辅，所以再向姊夫盖佐二世求援。但是盖佐二世以与拜占庭帝国开战为借口，暂不赴援。匈牙利辅助伊贾斯拉夫二世在1150早春重新占领基辅，1150年秋天，盖佐二世率军与加利奇公爵弗拉基米尔科·沃洛达列维奇作战，他攻陷萨诺克，但是其将军受贿而怂恿盖佐二世于11月前从加利奇退兵。

1150年，盖佐二世派遣骑兵大军联合舅父塞尔维亚大公乌洛许二世对抗拜占庭帝国，可惜于1150年9月在塔拉河被拜占庭帝国打败，塞尔维亚大公只好接受拜占庭帝国宗主地位。曼努埃尔一世为了报复匈牙利，入侵萨瓦河与多瑙河之间的土地。鲍里斯因有拜占庭帝国大军相助，入侵匈牙利，蒂米什河河谷满目疮痍。盖佐二世由加利奇撤退回国，因为要保留实力而于1150年至1151年与拜占庭帝国签署和约。

1152年，盖佐二世与伊贾斯拉夫二世联合出兵加利奇，在桑河打败弗拉基米尔科·沃洛达列维奇的军队。此时鲍里斯又得到拜占庭帝国帮助率兵攻打匈牙利王国南部，可是盖佐二世再次打败鲍里斯，并与拜占庭帝国议和。

1154年，盖佐二世支持安德洛尼卡·科穆宁推翻曼努埃尔一世，但是曼努埃尔一世平定叛乱及收复失地。

## 继承问题

1157年，盖佐二世的三弟伊什特万得到舅父别劳许支持，意图推翻盖佐二世。当盖佐二世平定此次叛乱，伊什特万出逃至神圣罗马帝国投靠腓特烈一世，盖佐二世派出使者承诺襄助神圣罗马帝国出兵米兰公国，以换取他不支持伊什特万。伊什特万只好逃至君士坦丁堡。

1159年，二弟拉斯洛亦意图推翻盖佐二世。

1161年，得到来自新的艾斯特根主教卢卡奇的启蒙，盖佐二世不仅承认教皇亚历山大三世的合法性，而不是皇帝腓特烈一世支持的对立教皇威克多四世，同时他也放弃授职的权利。

1162年，盖佐二世逝世，葬于塞克什白堡，由他的长子伊什特万三世继承王位。

# 盖佐一世

描绘在匈牙利的圣冠下部的盖佐一世

盖佐一世（匈牙利语：I. Géza；1040年—1077年4月25日），匈牙利阿尔帕德王朝国王（1074年—1077年在位）。贝拉一世的长子、母亲是波兰国王梅什科二世的女儿主里切扎。

1040年，盖佐一世出生于波兰，当时父亲贝拉一世与兄长们正被逐出匈牙利。1048年，伯父安德烈一世登上王位，贝拉一世回国并获得三分之一的土地为公国。安德烈一世当时未有儿子，所以以贝拉一世为继位人。1053年，安德烈一世的儿子所罗门出生，这断绝了他的弟弟贝拉公爵的继承愿望。1060年，贝拉一世出走波兰，要求妻舅波兰公爵波列斯瓦夫二世的军事协助争夺王位。安德烈一世终于在决战中重伤去世，贝拉一世继承匈牙利王位。

1063年，神圣罗马帝国协助所罗门夺回王位而出兵匈牙利，两军并未交战，父亲贝拉一世死于意外事故，被自己御座上突然倒塌的华盖压死。所罗门于1063年9月再度加冕为国王，盖佐、拉斯洛及兰珀特兄弟三人被迫出逃波兰。当德意志大军退出匈牙利后，三兄弟由波兰回到匈牙利，于1064年1月20日在焦尔与所罗门达成协议，三人承认所罗门为国王，而所罗门赐回他们父亲原本拥有的公国。由1064年至1071年，他们堂兄弟之间紧密合作，相安无事，分别于1067年及1071年一同攻打波希米亚及拜占庭帝国。

1074年3月14日，盖佐一世由其妹夫奥洛穆克的奥托大军协助下击败所罗门。所罗门只好出逃，回到他的根据地莫雄马扎尔古堡，盖佐一世登上王位，被贵族们承认为匈牙利国王。所罗门只能在亨利四世的协助下统治莫雄马扎尔古堡及普莱斯堡。在盖佐一世逝世前数月，盖佐一世曾主动与所罗门议和。

1077年，盖佐一世逝世，当时他的儿子卡尔曼及阿尔莫什皆年幼，由他的弟弟拉斯洛一世继承王位。

# 盖尔爱尔兰

9世纪爱尔兰修道院抄写员制作的《凯尔经》的一页

盖尔爱尔兰（爱尔兰语：Éire Ghaelach）是指史前时代晚期至17世纪盖尔人控制下的爱尔兰岛。在1170年代诺曼征服爱尔兰之前，整个爱尔兰岛都由盖尔人控制。在17世纪之前，盖尔人控制下的爱尔兰经济以牧业为主，而且当地人喜欢以物易物。

爱尔兰岛上的盖尔人起初信仰的是古凯尔特宗教。从五世纪开始，当地人开始皈依基督教。

公元9世纪，维京人开始劫掠爱尔兰海岸并在爱尔兰岛上建立定居点。 1169-71年诺曼征服爱尔兰后，爱尔兰岛上的大片地区被诺曼人控制，之后诺曼人与盖尔人冲突不断。亨利二世声称对爱尔兰领地以及整个爱尔兰岛拥有主权。然而英格兰王国方面控制的爱尔兰岛领土却一度不断缩小，最后只剩下帕莱地区。

1542年，爱尔兰议会授予亨利八世爱尔兰国王称号，爱尔兰领地变成爱尔兰王国。随后英格兰王国加紧控制爱尔兰岛。1607年，爱尔兰完全被英国控制，这意味著盖尔人无法继续控制爱尔兰岛，旧有的盖尔人社会秩序终结。

# 盖佐大公

在匈牙利编年史中的盖萨大公画像

盖萨大公（匈牙利语：Géza，约940年—997年2月1日）），匈牙利国父，匈牙利王国第一任国王伊什特万一世之父，宗教和文化改革家。盖佐大公是匈牙利大公陶克绍尼的儿子。970年或972年，盖佐继承其父成为匈牙利大公。盖佐采取中央集权化政策，这使他成为无情的统治者而声名远扬。记载他儿子伊什特万一世的生平的较长版本的文献Life of Saint Stephen, King of Hungary甚至指出，盖佐的双手“沾满了鲜血”。帕恩格（PálEngel）写道，盖佐对他的亲戚进行一次“大规模清洗”，这解释了从972年左右开始就没有提及阿尔帕德王朝的其他成员。Koppány继续统治外多瑙南部是这种引用不足的唯一例外。与匈牙利相邻的两个大国德意志王国和拜占庭帝国之间的婚姻联盟于972年建立两国达成和解。盖佐大公遂决定与神圣罗马帝国实现和平。首先，由神圣罗马帝国皇帝奥托一世派遣的名叫布鲁诺的僧侣于972年左右抵达匈牙利。匈牙利“代表”亦出席皇帝于973年在奎德林堡举行的会议。 

盖萨大公率领马扎尔人抛弃了原始宗教信仰，皈依天主教，并与罗马教廷建立联盟，这一系列措施为日后匈牙利王国的崛起奠定了坚实的基础。
