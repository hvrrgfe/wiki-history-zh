# 票号

山西平遥古城内日升昌票号
平遥日升昌旧址——临街门面
晋商鼎盛时期日升昌票号几乎垄断全中国金融市场。

票号，或称票庄、汇兑庄，是中国古代的一种连锁式金融商，有私人银行的功能。由于清代晋商几乎垄断了全中国汇兑市场，因此票号在一些文献会被直接称为「山西票号」或「晋号」。票号早期以承担汇兑业务为主，到清初许多票号又增加了存款服务。在清代，山西票号采用的特许经营策略，专门代表清政府的代理机构从事长途汇款，或向政府官员发于酬金。

## 历史

山西票号具体产生的时间，学术界看法很不一致，这些看法主要有：

- 明朝中叶，见日文《支那杂志·山西票庄》。

- 明末清初说。“据说开始是山西的康（亢）氏。清初，顺治年间李闯王造反，不利败走时，所有的金子携带不便，把军中所有的金银财宝放在康氏的院子里而去，康（亢）氏忽拾得八百万两，因此将从来谋一般人便利的山西汇兑副业改为本业，特创票号，至是该地的巨商都是康姓。”徐珂《清裨类钞》称：“相传明季李自成携巨资败走山西，及死，山西人得其资以设票号。”商务印书馆的《辞源》「票号」条文与《清稗类钞》及《支那经济全书》，皆认为「明李自成掳巨资败走山西及死，山西人得其资以设票号。」上海东亚同文书院木村欣一的《支那政治地理志》也主张山西票庄起至明末清初。

- 康熙朝说。“山西票号在康熙年间早已产生，但在当时票号寥若晨星，可以肯定不会太多。”据认为起于明末清初者多认为顾炎武同傅山因标局业务需要，于康熙十二年在太谷县沟子村创办了「志成信」票号。太谷县票号因而成为山西最有名的集中地。

- 乾嘉时期说。

- 道光初年说。陈其田《山西票庄考略》：“大概是道光初年天津日升昌颜料铺的经理雷履泰，因为地方不靖，运现困难，乃用汇票清算远地的账目，起初似乎是在重庆、汉口、天津间，日升昌往来的商号试行成效甚著。第二步乃以天津日升昌颜料铺为后盾，兼营汇票，替人汇兑。第三步在道光十一年（1831）北京日升昌颜料铺改为日升昌票庄，专营汇兑。”此前，中国的民间金融机构主要是钱庄。

会票（汇票）在明末清初已经出现。顾炎武《日知录》：

“钞法之兴，因于前代，未以银为币，而患钱之重，乃立此法，唐宪宗之飞钱，即如今之会票也。”

据《清高宗实录》卷1068载：乾隆四十三年十月:

“搜获现银仅二万四千余两，其会票期票所开，亦止四万六千余两”

会票制度已有了会票和期票之别。但未见有专营会票（汇票）业务的票号，应是由商号兼营会票（汇票）业务

中国票号博物馆（位于平遥县西大街日升昌票号旧址，1995年10月18日建馆开放）宣称“日升昌”票号是中国第一家专营存款、放款、汇兑业务的私人金融机构，创建于道光四年（公元1824年）。

道光八年（1828）江苏巡抚陶澍奏折称：苏州为百货聚集之区，山西、山东、河南、陕西等地商人到苏州贩货，银达数百万两，“俱系会票往来”。

早期经营票号的全是山西商人，称「西帮」。光绪初年有云南人李氏建立天顺祥票号。光绪九年（1883年）浙江宁波商人严信厚建立源丰润票号，时称“南帮票号”，势力较弱。红顶商人胡雪岩的“阜康”亦属于南帮。

票号与同时期的银号（钱庄的别称）区别于银号提供贷款服务，票号提供存款服务。仅提供兑换银票服务的小钱庄俗称钱店。步入清末民初，票号和银号提供的服务项目基本相同，而在民国时期二者均被银行陆续取代。

大票号有“南通北达，二盛二协”之称，例如日升通，日升达，百川盛、万源盛、协同庆、协同泰等。票号多为山西人所包揽，如大德通、合盛元、中兴和、蔚泰厚、百川通、志成信、大德恒、日升昌、存义公、蔚长厚、新泰厚、三晋源、协成干、蔚丰厚、协同庆、大德玉、蔚盛长等。又被称为“山西票庄”，民谣谓「金太谷，银祁县，榆次吃不完的米和面，平遥城，拉不满也填不平。」太谷为最大的票号中心，
平遥古城又是当时最大票号中心。平遥人雷履泰开设的日升昌曾获誉为“天下第一票号”，以“天下第一”，“汇通天下”闻名全国。

清朝中叶兴起的一系列山西票号或晋号尤其出名。光绪二十九年（1903年），北洋大臣袁世凯曾邀请山西票号加入天津官银号，但山西票号拒绝。

山西票号又称「晋号」，设立的城市计有：北京、张家口、天津、奉天、济南、扬州、江宁、苏州、芜湖、屯溪、河口（位于江西）、广州、长沙、常德、湘潭、汉口、沙市、重庆、成都、西安、三原、开封、周家口、上海、杭州、福州、厦门、汕头、营口、南昌、九江、桂林、梧州、昆明、贵阳、镇江、巴塘、里塘、打箭炉、自流井、迪化、甘州、南宁、解县、新绛、介休、曲沃、烟台、包头、兰州、肃州、归化、周村、张兰、宁夏、潮州、文水、汾阳、万县、雅安、康定、正阳关、通州、赊旗、兴化镇、禹县、博爱、清化、怀庆、寿阳、交城、喇嘛庙、凉州、盂县、库伦、吉林、长春、黑龙江、锦州、安东、安庆、运城、徐州、亳州、道口、济宁、获鹿、承德、多伦、赤峰、香港等。
