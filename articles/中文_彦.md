# 彦八井耳命

彦八井耳命（ひこやゐみみ の みこと，彦八井命、日子八井命，生、殁年不详）为日本第一代神武天皇与媛蹈鞴五十铃媛命所生的皇子，其兄弟有神八井耳命、神沼河耳命（《日本书纪》作神渟名川耳命，即绥靖天皇），异母兄弟则为当艺志美美命。别名有彦八井耳命、彦八井命、武国龙命、草部吉见神、高知保神等，为茨田连（まむた の むらじ）、手岛连之祖。

## 概要

《日本书纪》并未记录彦八井耳命之名，《新撰姓氏录》和《阿苏氏系图》却提到他是神八井耳命的儿子，属于茨田宿祢、茨田连、下家连、江首、尾张部、丰岛连的祖先。

### 古事记之记载

据《古事记》上卷之记载，庚申年八月神武天皇欲立正妃，广求世族豪门，听闻比卖多多良伊须气余理比卖貌美绝色，即迎娶之。神武天皇即位元年，立为皇后，生日子八井命、神八井耳命（かむやゐみみ の みこと）、神沼河耳命（かむぬなかはみみ の みこと，即为后来的绥靖天皇）。

神武天皇驾崩后，同父异母的兄长当艺志美美命为了夺下皇位，娶其后母媛蹈鞴五十铃媛命为妻，并计划暗杀日子八井命、神八井耳命、神沼河耳命等三位异母兄弟。但这三位兄弟反倒先下手为强，由神沼河耳命手持兵器杀死手研耳命。后者死亡后，日子八井命（茨田连、手岛连之祖）、神八井耳命虽为兄长，但因下手的是弟弟神沼河耳命，所以把皇位让给他，成为第二代绥靖天皇。

## 信仰

现今主祭彦八井耳命的神社主要有下列：

- 堤根神社（大阪府门真市）：与菅原道真共同被祭祀。

- 野口神社（奈良县御所市）

- 草部吉见神社（熊本县阿苏郡高森町）
