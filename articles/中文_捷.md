# 捷列克苏维埃共和国

捷列克苏维埃共和国的位置

捷列克苏维埃共和国（俄语：Терская Советская Республика），又称捷列克人民共和国，是1918年3月至1919年2月期间在旧俄罗斯帝国捷列克州存在的一个国家，是苏俄的构成国家之一。1918年7月时被并入北高加索苏维埃共和国。

《捷克斯洛伐克1968》（英语：Czechoslovakia 1968），或称为《捷克斯洛伐克1918-1968》（Czechoslovakia 1918-1968），是1969年一部关于「布拉格之春」，即苏联入侵捷克斯洛伐克的纪录短片。这部纪录短片是由美国新闻署在丹尼斯·桑德斯和罗伯特·M·弗雷斯科的的指导下制作，并由诺曼·戈林（Norman Gollin）担任图像设计。

《捷克斯洛伐克1968》在隔年赢得了奥斯卡最佳纪录短片奖，并于1997年因在「文化上、历史上或美学上具重要意义」而被美国国会图书馆选入国家影片登记表保存。

## 争议

1972年，参议员詹姆斯·L·巴克利获得了《捷克斯洛伐克1968》的副本来在纽约电视台上播放。美国参议院外交委员会主席J·威廉·傅尔布莱特基于对《史密斯－蒙特法案》的解释而反对该播送，该法案禁止美国新闻署制作的素材在国内传播。傅尔布莱特向司法部长投诉，但司法部基于对美国现行法律的解释拒绝干预播送。同年国会根据此事件修改了《史密斯－蒙特法案》，明确禁止美国新闻署制作的素材在国内传播。美国新闻署于1999年解散。

# 捷克斯洛伐克历史

冷战时期的捷克斯洛伐克

捷克斯洛伐克是一个在第一次世界大战之后从哈布斯堡王朝独立的国家。捷克人和斯洛伐克人在经济和科技发展水准上有较大的差距，但一个独立的捷克斯洛伐克使得两个民族之间的经济差距有所缩小。但两者之间的文化鸿沟始终无法弥补，这也成为在建国75年之后捷克斯洛伐克分裂的原因。在20世纪初期，在奥匈帝国内建立一个捷克斯洛伐克实体，使得奥匈帝国成为三元帝国的思潮开始出现并成长。

1918年10月28日，捷克斯洛伐克在布拉格宣布独立。

1929年，捷克斯洛伐克曾是世界第十大工业国，也是战间期东中欧唯一的议会民主制国家，但捷克斯洛伐克始终面临少数民族的问题。纳粹德国兴起之后，于1938年依《慕尼黑协定》占领苏台德区并成立军事行政区，之后撕毁协定将捷克并吞为波希米亚和摩拉维亚保护国，斯洛伐克也沦为德国的傀儡国斯洛伐克国。

1944年9月21日，捷克斯洛伐克被苏联红军解放。

1948年，捷克斯洛伐克成为一个共产主义国家。

1968年，捷克斯洛伐克爆发布拉格之春，导致之后被苏联侵略。

1989年，捷克斯洛伐克爆发天鹅绒革命，同时终结了共产主义政权。然而共产主义政权倒台之后，捷克和斯洛伐克在文化和经济路线上的分歧也浮出水面，最终导致捷克斯洛伐克在1992年解体，分裂为捷克与斯洛伐克两个国家。
