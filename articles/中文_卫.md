# 卫星国

卫星国的代表例子“东方集团”，指被苏联控制或支配的共产主义国家。

卫星国（英语：Satellite State）是一类在表面上宣称自己为独立国，但实际上的政治、经济、军事却受另一国严重控制的国家，属于从属国的一种。

“卫星国”一词最主要用在冷战期间，主要指在受到苏联的影响，且参加《华沙公约组织》的所有中欧及东欧国家。另外，东亚的蒙古人民共和国（1924－1990）和唐努图瓦虽然未参加华约，但也时常被算在内。冷战时，这个词在西方国家的语境中代表着苏联的霸权主义，受苏联影响的国家只能充当围绕在其身旁的卫星，无法获得与苏联平等的权力。以最广义的角度来说，这个词也可指冷战时一切被苏联影响的共产国家，例如朝鲜民主主义人民共和国（尤其是在朝鲜战争时）、古巴共和国（尤其是在1972年古巴加入经互会时）和北越（越南战争时）。虽然“卫星国”这个词主要用来描述苏联控制下国家，但也可用于美国控制下的国家，例如越南战争时的南越。在发生战争或者政治对抗期间，卫星国会被当做是宗主国与其敌国之间的缓冲国。

在西方用法中，“卫星国”很少用来指代那些苏联势力范围之外的共产国家；而在苏联自己的用法中，该词只用于纳粹德国、法西斯意大利、日本帝国的傀儡国。依《牛津英语词典》的文献记录，英语中的“Satellite state”一词汇最早在1916年时就已经出现。

# 卫瓘

卫瓘（guàn）（220年—291年），字伯玉，司隶河东安邑人，三国时期魏国、西晋的大臣，魏国侍中卫觊之子，出身书法世家。及长仕于魏国，担任廷尉、镇西将军；以持节监军入列伐蜀大军。灭亡蜀汉后，因谨慎瓦解钟会的叛乱而受重用。魏晋交替后，曾出镇幽州，削弱了北方鲜卑的势力，后入朝任尚书令，官至太保。后受贾后诬陷，与其子孙一同为楚王司马玮捕杀。

## 生平

卫瓘十岁时，父亲就去世，表现至孝过人，承袭父亲闵乡侯爵位。成年后，当上尚书郎。尚书台是权力中心，而彼时曹魏法度严苛、政派不一，母亲陈氏很担心他身居此位会得罪人，故卫瓘自求转任通事郎，后又转中书郎。入仕十年间，曹魏历经权臣专政，卫瓘却能巧妙在之间游走，不过份亲近任何一方，也做得称职，傅嘏因而看重卫瓘，称他是宁武子。以后累经升迁，升任散骑常侍。魏元帝即位后，卫瓘转任侍中，持节慰劳河北。后转廷尉卿，因通明法理，每参听讼案，不论案情大小都必依实情处理。

# 卫君角

| 卫君角

 | 统治 | 前241年－前209年
 | | 谥号
 | 无

 | 政权 | 卫国

卫君角（？—？），姬姓，子南氏，名角，为秦国所立的卫君，是战国时期诸侯国卫国的末代君主。前241年秦置东郡（今河南濮阳、山东聊城一带），徙卫君角至野王（河南沁阳）。

前209年，卫君角被秦二世废为庶人，衞国灭亡。

## 年表

杨宽考证认为其立年在前241年，他还认为卫君角不是卫元君之子。

卫君角元年（前241年），秦立卫国姬姓后裔角为卫君，迁徙至野王县作为傀儡。

卫君角二十一年（前221年），秦统一天下，立为始皇帝。

卫君角三十三年（前209年），秦二世废卫君角为庶人，卫国绝祀。

# 卫兵米南德

卫兵米南德（希腊语：Μένανδρος Προτήκτωρ），拜占庭帝国历史学家，生于公元6世纪中叶君士坦丁堡，生平记载于《苏达辞书》，他记载了拜占庭帝国公元6世纪的历史，是有关当时重要的史料。
