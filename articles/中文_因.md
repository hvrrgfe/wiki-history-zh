# 因戈瓦尔·雅罗斯拉维奇

因戈瓦尔·雅罗斯拉维奇（乌克兰语：Інгвар Ярославич，罗马化：Inhvar Yaroslavych，?—13世纪）曾于1202年和1214年担任基辅大公，他是雅罗斯拉夫·伊贾斯拉维奇之子，弗拉基米尔·莫诺马赫的重外孙。

1180年，因戈瓦尔·雅罗斯拉维奇决定与留里克·罗斯季斯拉维奇共同对抗切尔尼戈夫的斯维亚托斯拉夫·弗谢沃洛多维奇，据《伊戈尔远征记》记载，因戈瓦尔虽勇敢善战，但一直都在极力避免与周边势力强大的近邻发生冲突。例如，因戈瓦尔就在1183年拒绝被加利奇公国驱逐的弗拉基米尔二世·雅罗斯拉维奇在多罗戈布日避难。从史料中，我们似乎能看出因戈瓦尔一直对弗拉基米尔·雅罗斯拉维奇之父雅罗斯拉夫·奥斯莫梅斯尔存有戒心。不久后，因戈瓦尔从哥哥弗谢沃洛德一世·雅罗斯拉维奇处继承了卢茨克王公头衔。1202年，罗曼·姆斯季斯拉维奇（伟大的罗曼）与大窝弗谢沃洛德达成协定，让因戈瓦尔取代留里克·罗斯季斯拉维奇（留里克二世），成为基辅大公。同年，留里克二世在奥利戈维奇家族和库曼人的协助下夺回大公之位。1204年，因戈瓦尔与贝尔兹的亚历山大协力攻克弗拉基米尔-沃伦斯基，战事胜利后，因戈瓦尔当即受封弗拉基米尔-沃伦斯基王公，但这惹恼了当地的波雅尔们，亚历山大很快就取代了因戈瓦尔。在1208-1211年间，因戈瓦尔将其子派去支援加利西亚的丹尼尔，帮助后者与诺夫哥罗德-谢韦尔斯基的勇者伊戈尔的诸位儿子作战。1212年，因戈瓦尔与姆斯季斯拉夫·罗曼诺维奇共同对弗谢沃洛德·斯维亚托斯拉维奇（即弗谢沃洛德一世，外号‘凶狠的弗谢沃洛德’）发起进攻，最终攻占基辅。在别尔哥罗德基辅斯基附近结束了一场战斗后，因戈瓦尔主动将基辅城让给姆斯季斯拉夫·罗曼诺维奇，之后前往卢茨克。

# 因德日赫一世

因德日赫一世（捷克语：Jindřich I.，1448年—1498年），明斯特贝格-奥莱希尼察公爵，父亲是波希米亚国王波杰布拉德的伊日。

## 家庭

1467年，因德日赫与布兰登堡选侯阿尔布雷希特三世的女儿乌尔苏拉结婚，两人共有3子1女：

- 阿尔布雷希特（1468年—1511年）

- 伊日一世（1470年—1502年）

- 玛克塔（1473年—1530年）

- 卡雷尔（1476年—1536年）

# 因陀罗补罗 (占婆)

占婆地图

因陀罗补罗（梵语：इन्द्रपुर Indrapura）是占婆联邦中阿摩罗波胝的首府，在梵语中意思是「因陀罗之城」。在875年至1000年期间，因陀罗补罗是占婆的首都，被中国史料称作「旧州」。该城遗址位于今日广南省升平县同阳村附近，距离岘港市不远。

占婆第五王朝时期，占婆首都位于宾童龙的毘罗补罗（Virapura）。约在875年，第六王朝君主因陀罗跋摩二世将都城迁回北方，建立因陀罗补罗城，并以之为首都。因陀罗跋摩二世信奉大乘佛教，因此在城中建立了一座佛教寺院。这座寺院在越南战争中被炸毁。

982年，大瞿越皇帝黎桓攻打占婆，占领因陀罗补罗，杀死占婆国王篦眉税，夷平城池，将大量人口掳到北方。此后占婆首都自因陀罗补罗迁往毘阇耶。
