# 倾奇者

前田庆次，为倾奇者代表人物之一

倾奇者（日语：かぶき者 / 倾奇者 / 歌舞伎者／かぶきもの，罗马化：Kabukimono）是日本战国时代后期至江户时代初期的一种社会风潮。特别在庆长至宽永年间（1596年～1643年），于江户和京都等都市中流行。倾奇者是指喜好异风、穿上光鲜的衣著、以及有著超越常识行为的人（简而言之就是倾向奇异者），而爱好茶道和和歌等事物的人则被称为「数寄者」（或数奇者），而倾奇者和数奇者都有标新立异之人的意思。

## 解说

在日本古时，男性的衣着都是浅黄色和绀色等非常平实的颜色。但是倾奇者则喜爱鲜色的女性衣著羽织，袴则用动物皮包著等无视常识且非常华丽的服装。其他的有爱用天鹅绒制的襟，发型以「立髪」、「大髭」、「大额」、「鬓切」、「茶筅髪」为主，配戴很大的刀、脇差、朱红色的鞘、很大的锷、以及使用大型的烟管等，在当时被视为异常的风潮，被称为「倾奇大人」（かぶきたるさま）并流行著。

许多都会组成一个团体并巧取豪夺，进行很多暴行。而且会炫耀自己的武勇而四处打架，甚至有周围厮杀的情况。在路口中比剑、相扑、跳舞等，喜好在热闹的地方进行非法、超常的行为，与众道和吸烟的风俗亦有密切关联。

重视同伴间的信义，不惜生命都会坚守这个原则。在庆长17年（1612年）被捕缚和斩首的倾奇者大鸟逸平即使受到严刑拷问，最后亦没有供出同伴的身份，还讽刺地写出全国大名的姓名；而且在配刀上刻上「廿五まで　生き过ぎたりや　一兵卫」（意思是能活到廿五岁已经太多了）等字，显示出无惧死亡的意志。

而成为倾奇者的多数是被称为「若党」、「中间」、「小者」等武家奉公人。他们没有武士身分，并被武家雇用，负责持枪、取草履等杂务，因此生活相当贫穷而不安定，许多都是在合战中的足轻和跑腿，被鼓吹趁机略夺的行为、以及自由并暴力地生活，不过在战乱时代终结后没有归所，在时代变迁下显得不适应，于是产生反社会行为，以及在转瞬即逝的人生中出现特立独行的情况。

一方面，倾奇者因为乱暴而被视为非法者并被讨厌，另一方面则因为洒脱的生活方式而得到赞扬。而不只是武家奉公人，有时连町人和武士等旗本和御家人都会成为倾奇者。宽永年间开始在江户出现的被称为旗本奴、町奴的无赖集团就是倾奇者的一种。庆长8年（1603年），出云的阿国以倾奇者的风俗为基础而创立的舞蹈，马上就在全国中流行，这就变成后来的歌舞伎的原型。

倾奇者文化在庆长期间最为盛行，同时亦因为幕府和诸藩采取严厉的政策而很快消失，但是虽然上述的奇异暴行被消去，但是他们的美学则在被称为歌舞伎的艺能中流传下去。

《倾国倾城欲海花》（法语：Lucrèce Borgia；义大利语：Lucrezia Borgia）是一套1953年法国-义大利合拍的古装剧情片，玛丁·嘉露和柏杜劳·雅曼德列治主演。此片改编自德国编剧艾佛雷多·谢罗考的一本小说，由克里斯蒂安-雅克导演，他也同塞西尔·圣-劳伦和贾克·希古一起合作撰写了剧本。主要讲述义大利文艺复兴时期波吉亚家族的故事。

电影曾于1954年在香港上映，2009年5月26日在美国发行DVD。
