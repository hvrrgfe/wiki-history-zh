# M·R·詹姆斯

蒙塔格·罗德斯·詹姆斯 OM FBA（英语：Montague Rhodes James，1862年8月1日—1936年6月12日）是一位英国作家、中世纪学者，剑桥大学国王学院（1905-1918）和伊顿学院（1918-1936）院长，也是剑桥大学的校长（1913-15）。

詹姆斯作为中世纪学者的工作受到高度重视，但最令人难忘的是他的鬼故事，有些人认为他的作品是该类型的最佳。他为新世纪重新定义了鬼故事，放弃了许多前辈的哥特式陈词滥调，使用了更现实的当代背景。然而，他的主人公和情节往往反映了他自己的尚古兴趣，包含古文书、歴史遗物、史迹等元素。因此，他被称为 "尚古鬼故事"的鼻祖。

Memory of Mankind（简称MOM，意为“人类记忆”）是2012年发起的一项文化保存计划，旨在成为“我们时代的时间胶囊”，保留人类文明当前的知识，防止其被后世遗忘或因社会失忆症消失。数据刻在陶瓷板上后存储在哈尔施塔特的盐矿里。和政府运营的档案馆不同的是，MOM允许个人提交图片与文字，更为“草根”。
